ESP32を搭載しており、Bluetoothでの通信が可能な中央制御基板。他の基板と通信する用とロボマス等と通信する用の２つのCAN系統がある。外部からの信号で動かせるMD基板用の端子もある。基板に挿した状態だとesp32にファームウェアを書き込めないことやLCDのコントラスト調整ができなかったりといくつかの欠陥を抱えているのですでにあるものを見ながらパターンカット、違法建築を行うことを推奨する。  
そのほかの欠点としてはピンヘッダを用いてESP32とLCDを付けることを想定しているので分厚くなることがある。
